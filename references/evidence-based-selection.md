# Evidence-based figure acceptance test

The video-derived cases provide candidates. This gate decides whether a candidate is actually an upgrade.

An upgraded geometry is accepted only when all relevant conditions pass:

1. Define the primary reading task: exact lookup, comparison, trend, distribution, composition, topology, spatial pattern, or uncertainty.
2. Prefer common-scale position for exact comparisons, followed by non-aligned position and length. Do not make angle, area, volume, perspective depth, or saturation carry the primary exact comparison.
3. Reflect independent, paired, repeated, longitudinal, or hierarchical study structure in the layout.
4. Show all observations for small continuous datasets. Use transparency, beeswarm, density, binning, or contours as overlap increases.
5. Distinguish sample spread, parameter uncertainty, and future-outcome uncertainty. Label SD, SE, CI, PI, or credible intervals explicitly.
6. Use monotonic sequential color for magnitude, a true reference-centered diverging map, and redundant encodings for accessibility.
7. Keep zero baselines for bars; prevent occlusion, false linkage, radius/area confusion, and unexplained dual-axis scaling.
8. Prefer aligned small multiples over decorative 3D or complex polar layouts when they support the same task more accurately.

If a candidate fails a critical condition, preserve the basic geometry and upgrade only the data visibility, typography, layout, annotation, and palette.
